# ProfileUp AI — النسخة الداخلية

نظام داخلي مبني على Streamlit لإنشاء سيرة ذاتية احترافية خلال ثوانٍ. 
يعتمد على معالجة اللغة الطبيعية لتحويل معلومات المستخدم إلى CV منسق وجاهز للتحميل.

---

## المميزات
- بناء سيرة ذاتية كاملة تلقائيًا
- صياغة احترافية للملخص والخبرات
- اختيار المهارات المناسبة تلقائيًا
- تنسيق جاهز ومتوافق مع ATS
- واجهة عربية بسيطة وسريعة

---

## طريقة العمل
1. إدخال معلومات المستخدم 
2. تحليل البيانات باستخدام نماذج لغوية 
3. توليد أقسام السيرة الذاتية 
4. تنسيق المحتوى تلقائيًا 
5. إنشاء ملف PDF جاهز

---

## التقنية المستخدمة
- Python 
- Streamlit 
- Groq API 
- معالجة نصوص متقدمة
